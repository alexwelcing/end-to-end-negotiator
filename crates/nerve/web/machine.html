Separate networks, wired by events, running as one machine. ← the drag lab

Each panel is a block: an interface with its own trained network. Nothing joins them but wires from one block's events to another's actions, declared in the machine document below. Every tick, every block that stepped is checked against its spec (green) and the whole machine against the composed oracle. Grab anything while it runs: that block is held, its deliveries queue, the rest keeps going, and the cascade resumes when you let go.
