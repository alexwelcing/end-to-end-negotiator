Nerve Drag Lab

Interfaces that are neural networks, not code.

Each tab is a small interface with no code behind it. A spec says what is allowed, and a network trained from that spec runs it. Click an action and the network computes the next state while the spec checks its answer. Drag a handle and the states the spec allows compete to land under your pointer.
